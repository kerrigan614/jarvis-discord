What the bot does

Core features

J.A.R.V.I.S. supports the day-to-day operation of two MARVEL Strike Force Discord communities. Availability and behavior depend on each server's configuration and channel permissions.

Moderation and server safety

  • Automated message filtering and configured message deletion.
  • Warnings, mutes, moderation records, and event logging.
  • Message cleanup and member reports for moderator review.

Member and role management

  • Welcome and departure notifications triggered by membership changes.
  • Automatic roles, configured role restoration when members rejoin, and temporary roles.
  • Notifications when member roles change.
  • A server information channel displaying total member count.

Message and channel automation

  • Counting channels that evaluate ordinary messages for the next valid number.
  • Automatic reactions and reaction-based karma in designated channels.
  • Message voting, announcement publishing, and slowmode controls.

Community features and notifications

  • Member leveling based on message counts and configured voice-channel participation.
  • Giveaway functionality.
  • RSS, Reddit, external stream, and YouTube notifications.

Administration

Administrators use permissions controls, scheduled commands, aliases, and other bot management utilities to configure server behavior. J.A.R.V.I.S. also supports traditional Red-DiscordBot text commands.

Discord data needed for these features

Membership events and member information support timely welcome messages, role assignment and restoration, role-change notifications, moderation, and the member counter.

Message content allows the bot to evaluate ordinary messages for counting, configured filtering, and other message automation. These features can act without the author invoking an application command. Text commands and submitted reports also use message content.

The total-member counter measures server membership. The described functionality does not depend on individual online status or activity monitoring.

Processing data for a feature and retaining it are different. See the privacy policy for the data retained by leveling, karma, role restoration, moderation, and other configured functionality.
