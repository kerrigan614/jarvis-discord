What the bot does

Core features

J.A.R.V.I.S. supports the day-to-day operation of two MARVEL Strike Force Discord communities. Availability and behavior depend on each server's configuration and channel permissions.

Moderation and server safety

  • Configured message deletion and cleanup, including timed removal in selected channels.
  • Warnings, mutes, moderation records, and member reports for moderator review.
  • Message edit and deletion logging in the private #server-logs channel, accessible only to moderators and administrators.
  • HTML transcripts of removed messages posted in #server-logs for staff review.

Message filtering in the official server is handled by Discord's AutoMod rules.

Member and role management

  • An automatic welcome DM when a member joins the official server, plus private member join and leave notifications in #server-logs.
  • Restoration of a small, configured set of moderation roles when members rejoin, including @Muted, @Punished, @No Invites Allowed, and @React Restricted.
  • Temporary roles, reaction roles, and self-assignable roles through configured dropdown menus.
  • Notifications when member roles change.
  • A dedicated channel named Members: [count], updated as members join or leave.

Message and channel automation

  • Counting channels that evaluate ordinary messages for the next valid number, automatically delete out-of-sequence entries, and track configured community counting goals.
  • Automatic reactions and reaction-based karma in designated channels.
  • Message voting, announcement publishing, and slowmode controls.

Community features and notifications

  • Member leveling based on message counts and configured voice-channel participation.
  • Giveaway functionality.
  • RSS, Reddit, external stream, and YouTube notifications.

Administration

Administrators use permissions controls, scheduled commands, aliases, and other bot management utilities to configure server behavior. J.A.R.V.I.S. also supports traditional Red-DiscordBot text commands.

Discord data needed for these features

Membership events and member information support timely welcome messages, private join and leave logs, restoration of selected moderation roles, role-change notifications, and the member counter. These features respond to membership changes without requiring a command.

Message content allows the bot to evaluate ordinary counting messages and include available content in private message edit and deletion logs and cleanup transcripts. These features use messages that members independently post, edit, or delete. Traditional text commands and submitted reports also use message content.

The total-member counter measures server membership and does not depend on individual online status.

Processing data for a feature and retaining it are different. See the privacy policy for the data retained by leveling, karma, role restoration, moderation, and other configured functionality.
