J.A.R.V.I.S.

J.A.R.V.I.S. is a private, self-hosted Discord bot used in two MARVEL Strike Force communities: the official MARVEL Strike Force Discord server and the operator's private alliance server.

It provides moderation, member and role management, message automation, community utilities, leveling, notifications, and administrative tools. Features are configured separately for each server.

The bot is maintained for these two communities. It is not publicly installable or distributed for use in other Discord servers.

Built with Red-DiscordBot

J.A.R.V.I.S. is an instance of Red-DiscordBot, an open-source modular bot framework licensed under GNU GPLv3, with a curated collection of community extensions called cogs.

Privacy requests

Contact the operator through Discord using -contact followed by your privacy request. If that command is unavailable, contact a server administrator privately and ask to be connected with the J.A.R.V.I.S. operator. The privacy policy explains data deletion and the available commands.
